AI USAGE SUMMARY

AI was used only in the areas where the assigments said that is was allowed. The AI worked as a tutor, not a replacement.

How AI was used

To explain the human written SmartCare prototype in clean simple terms

To identify any limitations present in the human version

To suggest improvements without rewritting the program

TO generate an alternative booking function

To provide a controlled Improvement(preventing overlapping appointment times)

Prompts used
“Act as a Python tutor.”

“Explain what the code does.”

“Identify three limitations.”

“Suggest improvements.”

“Create a simple beginner-friendly Python function.”

“Choose exactly one controlled improvement.”

Verification
All AI code was

Executeed in Python

Tested with both normal and unusual inputs
Checked for errors and assumptions

AI supported learning, but all testing, decions and final code uses were done manually.
